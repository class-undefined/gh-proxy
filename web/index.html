01 / AUTHENTICATION

凭据留在客户端

HTTPS 使用你自己的 GitHub 凭据；SSH 沿用已有公钥。网关不托管个人身份。

02 / PERMISSIONS

授权仍然需要两道检查

网关策略与 GitHub 权限共同约束请求。页面中的命令不会授予额外权限。

03 / CONNECTIVITY

路由就绪 ≠ 平台可达

状态来自配置与进程计数。实际连通性请通过 clone、fetch 或授权 API 请求确认。
