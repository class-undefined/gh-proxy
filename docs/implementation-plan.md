## 验收矩阵

| 范围 | 场景 | 预期 |
| --- | --- | --- |
| SSH 身份 | 客户端使用已有公钥经网关连接 GitHub | 由 GitHub 完成认证，无需托管用户私钥 |
| SSH Git | clone、fetch、push、tag 推送 | 按远端账号权限成功或拒绝 |
| SSH 限制 | 未允许来源、目标或端口 | 网关拒绝连接 |
| SSH 边界 | 同用户访问其他有权仓库 | 网关不声称有仓库过滤能力 |
| HTTP 读取 | 授权仓库 clone、fetch、pull | 成功 |
| HTTP 写入 | 读写仓库 push、tag 推送 | 成功 |
| HTTP 越权 | 非白名单仓库或只读仓库写入 | 服务发现及 RPC 均执行拒绝策略 |
| API | 授权 Release 查询、创建、更新 | 仅允许配置范围内的操作 |
| 附件 | 授权附件上传、下载和受控跳转 | 正常传输，保留仓库授权上下文 |
| 附件越权 | 未授权仓库、未知目标、恶意重定向 | 拒绝，认证头不泄露 |
| HTTP 出站 | HTTP_PROXY、HTTPS_PROXY 及小写形式 | 按目标协议和约定优先级选路 |
| SSH 出站 | ALL_PROXY、all_proxy 与 SOCKS DNS 模式 | 使用所选上游与解析位置 |
| 绕过规则 | NO_PROXY 边界、端口及大小写冲突 | 按文档匹配，直连须显式允许 |
| 无代理 | direct / deny 两种模式 | 明确直连或明确拒绝 |
| 代理失效 | 不可达、认证失败、超时 | 请求失败，不回退直连 |
| 服务管理 | 重启及配置读取 | 服务恢复，策略仍生效 |
| 保密 | Token、认证头、代理密码、签名 URL | 日志、错误和状态中均不出现 |

自动化测试优先覆盖策略边界、协议识别、代理选路和跨域凭据处理。真实平台集成测试使用专用测试仓库和最小权限凭据，写入或发布前明确测试对象，避免影响业务仓库。
